N&S ATELIER — ACTUALIZACIÓN DEMO PREMIUM JARDÍN DE SEDA
=======================================================

QUÉ CONTIENE
- Tu web comercial index.html con el diseño premium añadido al catálogo.
- Los seis demos que ya tenías.
- El nuevo demo en: demos/jardin-de-seda/index.html
- Video ORIGINAL de apertura: assets/apertura-original.mp4
- Música instrumental ORIGINAL de ejemplo: assets/melodia-original.mp3
- Imagen original de sobre y dibujo de jardín.

INSTALAR SIN BORRAR GITHUB
1. Copia la carpeta local E:\ns-atelier-web a una copia de seguridad.
2. Extrae este ZIP.
3. Copia el CONTENIDO del ZIP dentro de E:\ns-atelier-web.
4. Acepta REEMPLAZAR index.html de la página comercial, no elimines .git.
   Si modificaste index.html recientemente, compáralo antes de reemplazarlo.
5. Abre VS Code, Live Server y comprueba el botón "Ver demo" en Jardín de Seda.
6. Ejecuta:
   git add .
   git commit -m "Agregar invitacion premium Jardin de Seda"
   git push origin main
7. En Netlify comprueba la ruta:
   https://nysatelier.netlify.app/demos/jardin-de-seda/
   (Solo si ese es tu subdominio ya publicado; si no, usa el actual.)

PERSONALIZAR UNA INVITACIÓN PARA CLIENTE
1. Duplica la carpeta demos/jardin-de-seda con nombre aleatorio, por ejemplo
   i/boda-a7h28k/ (incluye la carpeta assets dentro).
2. Abre el index.html de esa copia. Busca "const CONFIG = {" al final.
3. Cambia nombres, fecha, lugar, cronograma, vestido y regalos.
4. Completa googleFormUrl con el enlace público de tu Google Form.
5. Completa whatsappAnfitriones con el número del anfitrión: 51 + 9 dígitos.
6. Para cambiar música, reemplaza melodia-original.mp3 con una pista de la que
   tengas permiso. Para cambiar video, reemplaza apertura-original.mp4.
7. Cambia también imagen de sobre y nombres del sello para el nuevo evento.
8. Haz commit y push, y entrega al cliente la URL específica de su evento.

IMPORTANTE SOBRE PRIVACIDAD
- Este demo contiene datos completamente ficticios.
- Una URL no listada no es privada: cualquiera que reciba el enlace puede verla.
- Un repositorio público expone HTML, fotos y datos publicados. Para eventos
  privados de verdad se necesita control de acceso del lado del servidor.
- NO subas fotos privadas o datos personales de invitados sin autorización.
- Los botones de confirmación muestran instrucciones mientras sus enlaces
  sigan vacíos. NO envían respuestas hasta que los configures.
- Evita poner música de artistas comerciales sin licencia de uso en línea.

ANIMACIÓN Y AUDIO
- La apertura en video (aprox. 4,5 s) está generada de forma original.
- La música instrumental demo es sintetizada originalmente para esta muestra.
- Como exigen Chrome y Safari, el audio empieza después del toque del usuario.
- En iPhone, si no hay Fullscreen API para la página, se activa modo inmersivo.

No necesitas Tilda, un plan de pago ni copiar recursos de webs de terceros.
